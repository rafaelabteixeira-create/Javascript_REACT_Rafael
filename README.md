## FUNCIONALIDADES:
- Procurar Cartas pelo nome
- Filtrar Cartas por serem Obesas/Americanas ou Criaturas
- Obter uma Carta à sorte

## Como correr:
Escrever os comandos nesta ordem no terminal do bash:

 - cd /INICIO
 - npm install
 - npm run dev


 ## Onde é que o HTML foi construído em cada um? Como é que sabes?
 No caso da porta 3000 o HTML é construído no servidor através do Express, no caso da porta 5173 sabemos disso porque o Express mostra o HTML enviado pelo servidor enquanto o React apresenta o HTML na aplicação com uma div
